# Product Scope

## Что уже зафиксировано

ImageGen Studio — локальное desktop-приложение для генерации изображений, вдохновлённое InvokeAI / Forge, но с главным фокусом на управлении моделями, пресетами, snapshot'ами и воспроизводимостью настроек.

MVP должен доказать ценность не как “ещё одной формы Generate”, а как студии, где пользователь может:

- импортировать модель с CivitAI по ссылке;
- хранить локальную библиотеку моделей и metadata;
- генерировать изображения через локальный Python worker;
- видеть историю генераций;
- открывать immutable snapshot каждой генерации;
- создавать пресеты вручную и из старых генераций;
- применять пресеты полностью или по секциям;
- получать понятные ошибки по отсутствующим моделям/LoRA.

## Продуктовые нецели MVP

В MVP не нужно строить plugin API, workflow graph уровня ComfyUI, сложную систему наследования пресетов или полноценный browser CivitAI. Эти направления важны, но они не должны задерживать первый рабочий вертикальный срез.

## Северная звезда MVP

Пользователь может вернуться к удачной генерации, понять, чем она была сделана, превратить её в пресет и аккуратно применить эти настройки к новому эксперименту.
