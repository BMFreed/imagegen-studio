# ADR

В этой папке можно хранить Architecture Decision Records: короткие документы вида `0001-title.md`.

Хороший ADR отвечает на четыре вопроса:

- Какое решение принято?
- Почему оно принято?
- Какие альтернативы рассматривались?
- Какие последствия у решения?

Пока ключевые решения зафиксированы в [mvp-design-doc.md](../mvp-design-doc.md) и рабочих спецификациях в [specs](../specs).
