# Repository privacy preparation

The publication copy uses generic organization references, Sample Project A/B,
neutral demo prompts/tags, and portable developer paths. Other existing sample
project names remain unchanged. Commit authors, committers and their addresses
are intentionally retained.

## Current source

Demo names, IDs, selectors, preset payloads and shared project drafts change
together. Texture and portrait examples retain their technical embedding and
resource-binding seams. This changes demonstration content, not production
model inference, queue/storage rules, supported families or public promises.

Executable qualification helpers resolve the current home directory or their
repository location. They follow the existing InvokeAI configuration approach:
`InvokeAIAppConfig.root_path/find_root` in `config_default.py`, consulted at
`a61ac4fb75bec78d92885bf39bcf3ed3900a9bdd`. Documentation uses `~` and an external
storage placeholder instead of identifying one developer's machine.

## History and evidence

A separate publication candidate removes the six retired HTML prototypes under
`docs/prototypes/` and replaces personal demo data and identifying paths in older
file versions. Its commit map permits comparison with the original history.
The active branch and remote history are not replaced during preparation.
Local orchestration refs, worktree metadata, reflogs and private rollback copies
are not publication refs and must not be sent with a mirror push.

Historical source hashes, revision references and runtime reports describe the
original private evidence bytes. They are not silently updated or relabelled as
execution of the anonymized sources. Exact pre-cleanup evidence and rollback
material remain private, outside the published repository. No new ML or installed
application qualification is claimed by this maintenance change.

Replacing the published history is a separate final operation. It requires a
fresh expected remote revision, a verified backup, independent checks of the
candidate, and explicit coordination before changing that remote branch.
