# Preset from an accepted Raster result

Base `master`, `56d8fc5`. Contract: [Presets](../features/presets.md), PP-005
and PP-006. This slice connects accepted Raster Layers to the existing detached
Preset Manager; Smart Patch source/target integration remains in phase 4.

## Prospective boundaries

Medium-risk authoring and high-risk immutable-provenance/IPC review. Main owns
the saved result configuration. A separate read uses the existing portable
configuration projection without composing the current Canvas or starting an
ML worker. No Project mutation, Save, Undo, seed allocation, resource repair or
model-policy change is part of creating a preset draft.

The renderer binds the reply to the captured tab, document, layer snapshot and
accepted-result identity, and ignores obsolete replies. The mapper copies only recorded
portable settings, the result's concrete expanded prompt pair and exact sidecars.
Missing optional facts remain absent with an explanation; legacy/imported images
without generation data cannot silently fall back to the current Project.
Seed, dynamic batch settings, execution/source context and internal Anima bundle
identities are excluded. Workflow comes from the result's saved mode. Preset
storage allocates an identity only after explicit Create; Cancel, guarded
navigation and recoverable failure retain the established detached lifecycle.

Qualification will exercise the real mapper and service, source-aware session,
existing preset storage/Apply/create neighbors, a causal semantic mutation with
green control and byte-exact restoration, and built Electron UI through actual
preload/Main/.igs/SQLite with physical restart. Fixtures supply strict accepted
metadata rather than claiming new inference. Visual checks use the approved
manager layout at normal and narrow sizes. Heavy checks run serially with finite
RAM/deadline and zero swap. No model downloads or new runtime copies are needed.
