## Confirmed data flow

Ordinary Raster row → comparison owner in ProjectView → preload/Main read →
cloned generation configuration plus optional pixel-derived current Canvas
mode → pure semantic comparison → existing `GenerationSettingsComparison`.
The existing entity surface owns the popover anchor and the presentation component
only renders sections/statuses, scroll and unchanged-settings toggle.

The renderer already receives a separate Project generation draft while a Patch
is selected. Ordinary current-side projection includes the Project primary bbox,
exact catalog, document-scoped actual seed and optional composition-derived mode.
Unavailable CPU composition preserves readable recorded settings and explicitly
marks the current mode unavailable. Mode must not be inferred from layer count.

Smart provenance has reusable concrete configuration without Size. It supports
four recorded modes and both model families; Anima companion identities contain
hashes/byte sizes rather than historical local registry IDs. Current containment,
active member and owned asset identify the source. Historical target IDs remain
lineage and cannot resolve today's owner. Missing/locked/hidden/outdated state
does not itself invalidate immutable metadata inspection.

## Invariants and implemented boundary

- Keep ordinary strict transport and result-to-preset routes intact. A dedicated
  strict Smart comparison envelope binds document/revision, owner, exact active
  variant/result and asset hash; only portable generation configuration crosses.
- Capture ownership before awaits; recheck the same coordinator, document epoch,
  revision, active member and asset after optional current-Canvas inspection.
  Revision alone does not prevent edit/Undo ABA.
- Preserve the existing worker-optional read behavior. Baseline settings require
  neither current source pixels nor installed generation resources. Unknown mode
  and resource availability must remain explicit rather than equal by default.
- Share semantic field projection without fabricating ordinary Size or local
  Anima identities. Preserve concrete prompts/embedding refs, exact resources,
  configured LoRA order/enabled/weights, family sampling, recorded advanced
  options and actual seed, including zero/absence/null distinctions.
- Exclude Smart mask, bbox, internal resolution, blend/opacity, source revisions,
  prepared image identities, execution IDs and Regional Guidance. A generic
  Size section is absent for Smart provenance; ordinary Raster Size remains.
- Opening/expanding/closing/dismissing never selects a layer, activates a variant,
  flushes/seals drafts, resolves seeds, changes library policy, writes staging,
  adds Undo or implicitly Saves. No Apply/Recall/Restore/preset creation control
  belongs to the popover.
- Renderer requests invalidate on owner/active-member/context changes and wait
  for acknowledged drafts. Current Project settings/catalog/seed recompute the
  current side without replacing the immutable baseline. Close/Escape restore
  the surviving source trigger; outside dismissal retains the clicked focus.

An inactive direct Compare action, variant-to-variant comparison, image
before/after comparison, Smart-target Apply, ML provisioning/inference and full
MVP/release are outside this slice. Active Patch and converted Raster menus are
the two scoped entry points.
