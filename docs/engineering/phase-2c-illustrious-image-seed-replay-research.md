`prepareNormalGenerationInternal` chooses `randomBytes(4).readUInt32LE(0)` once
before IMG/OUT expansion. The observer wraps that actual call without replacing

or admission; legacy profiles without this hook retain their existing behavior.

configuration must bind `(observedBase+offset)%4294967296`. Final operational
cursor and explicit Save snapshot equal `(observedBase+7)%4294967296`. Production
allows a valid worker-reported seed to differ from a scheduled seed; equality
here is an observed invariant of this selected installed worker, not a new
universal receipt restriction.

native comparison projects `{kind,context,workerJob}`, excluding transport
envelope fields and portable document identity/revision. Replay normalization

and resources remain exact. Requested policy stays
Random versus Fixed in raw contexts and accepted configurations. Same-pair
