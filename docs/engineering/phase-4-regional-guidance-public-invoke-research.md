## Settled versioned composition

`compositionProfile: 'invoke-canvas-v1'` is frozen explicitly. Its native
consumption differs intentionally from the earlier private raw-alpha profile:

- Authored world-alpha stays unchanged in capture/durable input. Consumption
  uses `alpha > 0`, then existing local nearest-eight mapping. Sampling the
  pointwise conversion avoids a second full plane. Display opacity is excluded;
  a zero plane stays zero.
- Both global text streams remain present with Everywhere coverage. Both
  positive and negative pooled sources are `current-canvas`.
- A literal-empty or absent local sign emits no conditioning stream; whitespace
  remains nonempty. Inherited negatives resolve the frozen global text, rather
  than a later draft. Authored/dormant values remain in the checked operational
  recipe even when that sign emits no stream.
- Layout is `cfg-negative-first`, with CFG strictly greater than one. Overlap
  and global participation follow this composition; there is no new weighting
  control, inverse-mask auto-negative, reference adapter or selected-pool UI.

New explicit Invoke encoding/geometry profiles carry these semantics through
the existing recipe and denoising owners. Unmarked legacy worker inputs retain
their old profiles. The marker is transported through the existing bounded
bundle; the worker advertises `illustrious-regional-invoke-v1`. Main rechecks
that exact capability before target composition and again at execution.

## Main ownership, dispatch and recovery

The public command supplies reviewed document identity, iterations and exact
replacement confirmation. The coordinator captures document/revision/epoch and
raster/regional owners before runtime acquisition. Main owns preparation,
operational seed, one planner item, recipe and request. Stale revision,
same-value epoch ABA and replaced-owner checks guard the captured work; runtime
refusal before preparation leaves no new job, while a late preparation failure
cancels the exact new publication.

Migration0021 extends only the queue operation CHECK through the existing
table-copy pattern. The new SQL/frozen discriminator is
`illustrious-regional-txt2img`; old `illustrious-regional` rows remain private.
No heuristic promotes historical private jobs or outputs. Public manager
counts/details/action snapshots and automatic FIFO routing include the new
operation; its claim retains the existing global running-slot CAS. Ordinary
claims exclude it, and private claims select only the old operation. Public
cancel/delete first verify a public manager identity; public Clear preserves
hidden private history. Lifecycle enumeration still owns both without counting
a candidate twice.

Replacement uses the existing reviewed candidate/job identities. Missing
confirmation returns the current impact. Old results remain until the new job
has qualified and entered durable admission; changed impact requires renewed
review. A late preparation failure after publication cancels the exact newly
admitted job. Uncertain cancellation/publication retains the existing fence and
inputs instead of reporting success. Normal/Smart dispatch retain their existing
owners. The legacy constructor's original metadata-preflight hook remains
unchanged; new public dispatch uses its explicit regional route.

Public Retry uses the saved input owner, public profile, status CAS and open
Project identity. It independently copies frozen target/recipe/alpha into a new
attempt; later authoring is not recomposed. Exact resources/capability are
reverified. Restart cancels unfinished computation and reconciles manifest-first
publication through existing receipts, without automatic native resume.

## Results, explicit Raster acceptance and finite scope

The new operation enters existing verified public candidate enumeration, signed
PNG/optional-thumbnail reads and queue-result navigation. Legacy private
enumeration and byte reads remain separate. Candidate publication keeps the
original frozen JSON/SHA, verified output identity and worker-confirmed seed.
Queue pruning does not consume a completed candidate. Save Candidate Image
reuses the native destination dialog, post-dialog candidate recheck and exact
create-only PNG export, without adoption or Project mutation.

Raster Add was already defined by
[Generation Results](../features/project/generate-mode/generation-results.md#normal-generation-acceptance)
and [Generation Provenance](../features/project/generate-mode/generation-provenance.md).
The new accepted-base projector first validates the original public operation;
it removes only operational regional/profile fields and projects existing
ordinary txt2img settings. Candidate identity and original payload SHA remain
checked; no substitute candidate or fabricated hash is introduced. Private
payloads cannot use that projection.

Mixed ordinary/public-regional selection uses frozen-bbox Raster placement, one
visible anchor, grouped Undo/Redo, journal, asset adoption, synced shadow and
captured-session tombstones. Existing layers/regions remain unchanged.
Completion/export/Add do not implicitly Save; explicit Save puts accepted state
into `.igs`.
Regional prompts, masks, references, coverage, pooled-source selection and the
composition marker stay out of every accepted-provenance group, settings
comparison and result-derived preset. The saved reusable settings cannot fully
reconstruct a regional run; portable schema and journal/Save formats are unchanged.

Admission is deliberately narrower than the feature's eventual family scope:
one static Current Canvas item; Illustrious epsilon, Euler/Normal, steps 1–200,
CFG `(1,30]`, CFG Rescale zero, explicit FP16 Embedded VAE, no enabled LoRA,
at most three enabled regions and no enabled-region reference images. Effective
global TI refuses before composition; local regional TI retains its exact
recipe/resource owner without a new trained-TI qualification claim. Brace syntax
and Images per click other than one refuse instead of being silently rewritten.

The actual target must remain transparent. Existing sides 8–2048/divisible by
eight, area at most 4,000,000 pixels, 32 MiB target, 128 KiB frozen SQL, 1 MiB
regional metadata, 64 MiB aggregate alpha and existing text/resource/row limits
remain admission bounds, not measured capacity. Opaque/mixed-alpha targets,
Anima regional execution, Smart regional execution and unsupported references
remain separate owners. Ordinary zero-region work and previously frozen
ordinary/Smart Retry retain their independent permissions.
