## Collector ordering and proof limits

The native collector returns different legal orders:

- assignment: global, left owner, right owner;
- swapped: left owner, right owner, global.

Ranges stay paired with their actual masks and streams. Validation resolves
prepared UUIDs by actual image/text/mask identity, rather than assuming submitted
node IDs or fixed ordinal rows. Each actual stream and pool matches its retained
independent Studio oracle in both cases. Assignment's entire native CFG bank
also matches the independent retained bank exactly.

The differently ordered swapped bank is **NOT_INDEPENDENTLY_RECONSTRUCTED**:
per-stream hashes alone cannot recompute the combined bank's bytes/hash. Actual
native context hashes, per-stream/concat/range/mask checks and the source path
remain evidence, but they are not promoted to an independent reconstruction of
that complete bank. The bank permutation also changes floating-point reduction
order, so the RGB contrast is not attributed uniquely to authored assignment.

Cross-application initialization and Torch CUDA-build differences remain explicit.
Unlike the preceding ordinary FP32-noise Studio control, these retained regional
Studio cases and installed Invoke both use the FP16 draw policy. That matching
policy alone does not prove cross-application initial-latent or image equality.

The oracle rejects an intentionally wrong owner mapping while accepting the
healthy retained mapping. This is **record-only sensitivity**, with no native
source mutation and zero extra GPU/model requests; it is not a new native RED.

## Visual outcome

ROOT views all four full originals; an independent image-only reader describes
randomized copies without prompt, case labels or key. The new Invoke assignment
contains two left-side apples and many blue/white vessels, including malformed
handles. The swapped image retains only a cropped lower-left apple, no right-side
apple and vessels across the tabletop. The retained Studio pair also misses the
intended reversal, with additional malformed objects in its swapped image.

New visual outcome: **0 PASS / 2 FAIL; reversal NOT_QUALIFIED**. Human acceptance
remains pending. Verified text/mask eligibility does not imply object ownership:
the unmasked global stream still includes both object nouns everywhere, and
self-attention/convolutions remain shared. Those source facts explain the scope
of the mechanism; this experiment does not isolate a sole cause or choose a new
global-support/composition default.

This closes the actual-reference assignment comparison without evidence for a
Studio-specific mask-routing defect. It does not prove absence of all defects,
general quality or public readiness. No further prompt/seed/sampler sweep or
attention rewrite follows this result. Ordinary-scene limitations and regional
association must remain distinct in subsequent acceptance.
