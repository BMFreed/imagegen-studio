## Separate mechanical and visual gates

The harness uses the existing loader, native loop, regional adapter, static image
conversion and exclusive provisional PNG publisher. Mechanical checks cover
checkpoint/live-component lineage, complete Main identity and text association,
all 70 native attention/SDPA sites on every step, signed contexts/permissions,
selected pools, time IDs, actual schedule/CFG/Euler/decode, source/RNG/restoration
and exact independently reopened RGB quantization. Repeat/ordinary comparisons
are explicit. Successful execution alone records **visual evaluation pending**.

Visual assessment uses unchanged PNG bytes without overlays. Anonymous order
hides seed and assignment labels from an independent image reader, who first
records actual objects, colors, positions, duplicates/fusion, leakage and visible
coherence/boundary defects. ROOT separately views the original full images and
joins the observations to the frozen assignment map. These are bounded agent
image assessments, not human user acceptance or general quality certification.

A finite visual PASS requires recognizable requested subjects for both seeds,
correct sides in assigned and swapped images, an actual side exchange, separated
objects and a coherent scene without severe leakage/merging or a conspicuous
mask-edge artifact. Baselines must support ordinary object recognition; random
baseline order is acceptable. Ambiguous images are inconclusive, not PASS.
Changed pixels, a colored half, valid masks or matching conditioning alone cannot
satisfy this gate. Applying a swapped requirement to a fixed assigned observation
must be rejected as a visual-rubric control without another ML request.

A separate valid source mutation swaps only regional positive permission-range
association after admission, preserving global/negative permissions and genuine
native computation. The assignment oracle must become semantic RED after PNG
publication, its zero-region control remain GREEN, and exact restoration return
both to GREEN. This tests the mechanical association oracle; it does not replace
visual evaluation.

## Visual result: not qualified

ROOT viewed all six original full PNGs. An independent reader first described
all six unchanged images in randomized order with prompt, seed and assignment
labels withheld; the mapping was revealed only after that reader finished.
The final assessment is **NOT_QUALIFIED: 0 PASS / 3 FAIL / 1 INCONCLUSIVE** among
the four assigned/swapped targets. The narrower placement gate is 1 PASS / 3 FAIL.

| Case | Observed result | Full visual gate |
| --- | --- | --- |
| Seed 123 assignment | Apples remain left, but multiple blue/white cups occupy both halves; duplicated and malformed vessels defeat separation/count/leakage criteria. | FAIL |
| Seed 123 swapped | Apple remains at the far left, cups remain across both sides, with malformed utensil-like forms. The required side exchange is absent. | FAIL |
| Seed 124 assignment | One apple left and one mug right satisfy placement, but the suspended, truncated-looking apple prevents a coherent-scene PASS. | INCONCLUSIVE |
| Seed 124 swapped | Apple remains left and mug right; the required side exchange is absent. | FAIL |

Both swapped cases fail the decisive side-exchange observation. Ordinary baselines
already show count or physical-coherence limitations, so the experiment does not
attribute every defect to regional masking. No conspicuous straight mask seam or
halo was observed. Neither changed RGB nor correct native association establishes
useful regional semantics for this fixed scene.

Rubric sensitivity has only a placement-component control: the observed seed-124
assignment passes apple-left/mug-right and fails the swapped requirement without
another ML run. There is no healthy full-quality positive control. The result is
a bounded agent image assessment for one scene and two seeds, not human user
acceptance or a general judgment of Illustrious quality. No prompt, seed, model,
mask or composition tuning followed image inspection.

## Remaining boundary

Global tokens remain eligible inside the chosen regions, and global pooled
conditioning remains whole-image. Permissions do not establish object ownership;
self-attention and later native computation can propagate effects across masks.
Binary sampling/threshold/max-pooling is not continuous soft-mask strength. A
negative visual finding therefore remains a result to explain rather than a
reason to tune the same attempt until it passes. The cause is not established.
A next composition/support comparison needs its own preregistered conditions,
ordinary-scene calibration and these same counterexamples. No proposed support,
pooling or overlap choice becomes a product default from this result.
