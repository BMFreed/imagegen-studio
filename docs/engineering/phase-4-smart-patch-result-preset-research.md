# Smart Patch accepted result → preset

Implemented and qualified for the three accepted-result origins below: **790
focused/neighbor tests, 181 prototype tests and 15 native checks pass**, with
typecheck, lint, build, source review and restored semantic mutation. The final

finite source-to-preset results, not full promise/release readiness.

## Scope and inspected baseline

The finite owner is `Save Preset from Result` from an active accepted Smart
variant, an exact inactive stored variant, or a Smart-provenance Raster produced
by explicit orphan conversion. Baseline: `master@10115df581d9` plus preserved
freshness, frozen Retry, orphan Raster and accepted-history changes. The complete

This is medium-risk detached authoring with a high-risk immutable-source/IPC
verification pass under the [research](research-protocol.md) and
[review](review-protocol.md) protocols. It supports PP-005 and PP-006; it does not
complete either promise. [Presets](../features/presets.md) owns the portable-field
boundary. Smart Compare, Smart-target Apply, trained inference, reproduction and
release readiness remain separate owners.

## Data flow and ownership

Layer menu or exact variant action → captured current accepted owner → strict
preload request → worker-independent Main read → whitelisted reusable payload →
detached create intent → existing Preset Manager → explicit Create → SQLite.

The current document/revision, parent/member identity and owned asset hash bind
the read. Current containment is authoritative; historical source layer IDs are
lineage. A request for an inactive member must never resolve the active member.
Main projects the result's frozen concrete configuration, not today's Patch
draft, authored prompt template, Canvas draft or catalog defaults.

The dedicated route keeps ordinary `RasterGenerationData` and comparison
validation intact. Widening that transport would invent Size or confuse Anima
component identities with reusable VAE settings. No staging lookup, worker,
catalog qualification, source composition, draft flush or prompt-history seal
is needed to copy accepted metadata.

## Product clarification and invariants

Every Smart-provenance source defaults to workflow `smartPatch`, including
recorded TXT/IMG/INP/OUT modes and converted Rasters. This origin-based rule is an
explicit clarification of the existing prototype's mode-based mapping. The
editor remains editable; this does not add Smart-target Apply.

- Copy concrete positive/negative prompts and embedding sidecars, exact model
  and resource references, recorded LoRA order/enabled state/signed weights,
  family sampling, guidance and applicable recorded advanced options.
- Preserve absence versus explicit empty lists, null VAE, zero and Auto. Anima
  companion encoders/VAE remain excluded; no Embedded VAE is invented.
- Omit Size, Seed by default, masks, bbox, internal resolution, compositing,
  source revisions, execution IDs and dynamic-batch settings. Smart world size
  may be 1px or nonaligned; neither it nor processing resolution is preset Size.
- Hidden/locked and outdated/unverified accepted sources remain readable.
  Missing installed resources warn without replacing recorded identities or
  blocking creation.
- Copying opens an editable detached draft. Cancel allocates no preset. Failed
  storage preserves edits for retry. Later source/catalog changes do not replace
  the detached draft.
- Source document, active variant, Undo, camera, `.igs`, seed cursor, immutable
  provenance and model-library policy remain unchanged. Ordinary Raster presets
  retain their recorded Size. Smart Compare retains its refusal.
- Late/crossed replies cannot open a stale editor. Focus returns only after the
  Manager leaves, to the surviving source control in the same Project.

fabricated geometry. Service/package tests cover both families, all recorded

accepted fixtures, absent runtime and missing catalog resources. They cover all

900×620 layouts, keyboard/focus return and unchanged source witnesses. Literal
PNG/provenance/package and consistent SQLite bytes are retained independently
of disposable payloads. These fixtures do not qualify inference or acceptance.
